
# Riviera Bar

Site institucional demonstrativo desenvolvido pela **MORAIS TECHNOLOGY**.

## Sobre o projeto

Apresentação digital do Riviera Bar, com identidade visual inspirada no estilo Art Déco, combinando tons escuros e detalhes dourados.

## Recursos

- Página inicial e apresentação do estabelecimento
- Seção gastronômica
- Coquetelaria
- Galeria de imagens
- Informações de localização
- Área de reservas
- Layout responsivo para celulares e computadores

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Publicação

Hospedagem por GitHub Pages.
